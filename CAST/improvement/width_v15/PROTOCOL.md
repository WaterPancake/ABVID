# Source-fold coverage calibration, v15

Preregistered before implementation or generation. V14's preliminary outer
coverage result is already known and is retained as a failed development
comparison. Complete its exact replay and delivery before executing v15.
This protocol uses only source folds to choose a width; it changes no outer
metric, threshold, sample budget, fitted parent, split or historical result.

## Source evidence and question

V14's fully replayed source winner is `spectrotemporal_context_T1`.
Mean source coverage is 84.628% car / 86.821% truck, yet the minimum
source-fold mean car coverage is only 79.580%. The exact v12 reference also
has a source car fold below 80% (79.646%). Passing a mean can conceal an
already visible source-group weakness. V14 source margins against both
controls pass, and it uses the same complete v11 fitted bank. No outer
descriptor or fitted parameter is needed to identify this source problem.

Test whether modest dispersion calibration of that source-selected prior
can meet coverage in every source fold while retaining the original mean
distance margins and spread limits. Earlier temperature trials on the
25-control model failed the margin criterion; those negative results remain
unchanged. The present population has the separately validated 69-control
representation and scoped group effects. This is a new comparison, not a
reinterpretation of the old temperature experiment.

## Fixed population transformation

Use exactly the v14 `spectrotemporal_context` virtual population. Let z be
each existing child's transformed vector: log spacing, centered log-ratio
harmonic/noise/envelope controls (floor 1e-8), and mixture logit (input clip
1e-4), with the unchanged v12 transforms. Compute mu separately per class,
giving equal weight to source groups, parents within group, and children.
Compute this center after the v14 population's existing bounds/restoration.

Test exactly T = [1.0, 1.1, 1.25, 1.5], one common T for both classes. For
T > 1, replace only noise, mixture and envelope coordinates by
mu + T * (z - mu). Restore each child's original spacing and harmonic
weights bit-exactly. Invert using the existing group-prior inverse and the
residual parent's original mean-log-envelope gauge. Retain the same bounds
and record every projection. Record upstream projection counts separately;
original parent ambiguity and boundary flags remain in the bank.

T = 1 must return the exact v14 samples and statistics without another
transform/inverse round trip. No random stream, child count, original parent,
or fitted value changes. Recompute prototypes from the expanded population
using equal group/parent/child weights. All three arms use that identical
population; the marginal control still resamples 69 scalar coordinates.
Preserve the v12/v14 direct-donor, child, phase and noise schedules for every
T, so the only sampling change is the declared deterministic width transform.

Freeze class centers, population hashes, prototypes, bounds and projection
counts before any generation. Exclude the source validation group before
every statistic; always exclude the outer group.

## Stronger internal selection; unchanged outer acceptance

First compute all existing source results and their original ranking keys
unchanged. A candidate is eligible only if it passes every original source
criterion AND its minimum joint mean coverage over the five source folds
is >= 0.80 in each class. A fold mean averages the same five fixed synthesis
seeds. This is an additional internal requirement, not a replacement or
relaxation of any criterion. It does not guarantee a new group's coverage.

Among eligible candidates, use the unchanged original ranking key. For a
complete diagnostic ranking when none is eligible, rank eligible first,
then the original keys; report failure and do not open outer data. A selected
T=1 reference must also stop without repeating its existing outer result.
Keep original mean-criterion passes and the stronger fold gate separately
visible in every summary, including failures.

Require the exact original fold/class/arm/seed score schedule, rejecting
missing, duplicated or extra rows before selection. Test that a candidate
passing all original criteria but failing one fold is rejected, and that
neither missing folds nor seed selection can manufacture eligibility.

Use the same 380 admitted H1 fold-0/seed-42 training IDs, five source groups,
50 samples/class/seed/arm, seeds [42,123,456,789,1024], q05-q95 coverage,
four equally weighted descriptor families, training-only scales, >=80%
coverage, >=2.5% W1 reduction versus each matched control in each class,
and joint family spread [0.5,2]. Do not fit any additional recording.
Preserve all restrictions on MELAUDIS, mixed caches, supplied synthesis,
military/reserved sources, datasets, splits, environments and baselines.

## Required checks and progression

Preserve existing tests and add numerical checks for the known width
transform, restored controls, equally weighted prototype/center despite
unequal group sizes, unchanged donor/child/waveform streams, finite bounded
rendering, exact T=1 reference, projection records, ancestry rejection and
stronger selection. Reject unregistered widths and non-finite values.

Replay all 30,000 source records and 600 scores, with all 150 T=1 v14
reference scores exact. Only a newly selected eligible T with complete
source replay can enter a separately frozen outer development comparison.
Generate all 1,500 outputs before reading the held descriptors, then replay
every generated waveform and all 570 raw held descriptors. Preserve all
failures and samples. Complete plots, audio review, timings and report.

The actual outer acceptance remains >=80% coverage and >=2.5% reduction
against each control in each class, plus the unchanged spread and technical
gates. Repeatedly exposed outer development is not fresh confirmation,
classification performance or independent physical-vehicle generalization.
