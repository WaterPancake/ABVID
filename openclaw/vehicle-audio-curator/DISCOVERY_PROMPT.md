# Initial discovery run

Inspect the project catalog and the existing proposals first. Then search authoritative
Wikimedia Commons and Internet Archive metadata for missing **background** recordings,
prioritizing road traffic, wind, machinery, construction, rain, and birds/insects.
Also look for one additional legally clear tracked-vehicle recording if available.

For every candidate, require an explicit license statement, creator, source/session
identity, and a stable media URL. Write one `proposals/YYYY-MM-DD-*.yaml` file using
the audio-source-curator schema. Do not edit `configs/audio_sources.yaml`, do not
invoke the collector without an explicit operator approval, and do not download media.
Summarize accepted/rejected candidates and explain every rejection.
