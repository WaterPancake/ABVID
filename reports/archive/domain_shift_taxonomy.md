PDF page numbers are one-based. **Author evidence** and **review interpretation** are distinguished below; unknown quantities are not estimated from conversions.

## Origins of shift

The following is a **review taxonomy**, grounded in the experiments cited in each row. A dataset boundary changes a joint distribution; it does not automatically identify a causal physical factor.

| Origin | Physical/signal change | Representation consequence | Evidence and unresolved attribution |
|---|---|---|---|
| Source mismatch | Engine/exhaust configuration, RPM/load, rolling/track excitation, modulation and relative component energy differ. | Harmonic templates, fixed spectral bands and learned embeddings can encounter class-conditional signals absent in training. | P02 describes stationary harmonics, missing jitter/modulation/turbulent noise and one engine configuration per class in its procedural sources. It does not replace only the source while holding the propagation renderer fixed. [P02, §2.2.1, §3.3, PDF pp.4, 14–16; P04, §5.3] |
| Propagation mismatch | Distance, orientation, trajectory, Doppler, ground reflection and multipath alter level and spectral/temporal structure. | Scalar normalization cannot remove frequency-dependent changes or recover masked components. | P05 explicitly limits its invariance claim; P09 station transfer reduces event accuracy. P02 implements several propagation mechanisms but provides no propagation-component ablation. [P05, §3.4; P09, §V; P02, §2.2.1] |
| Environmental mismatch | Surface changes excitation; weather changes paths and noise; competing sources mask or overlap the target. | Background shortcuts, shifted spectral envelopes, unstable fundamental estimates and mixed-class embeddings. | ACIDS terrain distributions differ; P02's congestion test uses artificial mixtures and includes training-source recordings. Weather-specific transfer remains unknown. [P13, chapter 3, §2.3; P02, §§2.5, 3.4, 4] |
| Sensor mismatch | Frequency response, bandwidth, noise floor, gain and channel processing differ. | Spectral coloration can survive resampling/normalization; discarded bandwidth cannot be restored by resampling. | P16 explicitly adapts between devices; P01 tests another microphone on the same events; P02 acknowledges AudioLDM's 16 kHz generation bandwidth. These are distinct interventions. [P16, §§2–4; P01, §§2.1, 2.5; P02, §§3.3, 4] |
| Dataset/annotation mismatch | Class definitions, class priors, event segmentation, clip duration, overlapping events and source grouping differ. | Decision boundaries and metrics change even if the physical transfer function is unchanged. | P01 adds bus/background relative to P02, changes datasets and representation, and uses balanced test subsamples. P02's congestion labels use greatest temporal overlap. Their headline F1 values cannot be subtracted to estimate an architectural improvement. [P01, §§2.1–2.5; P02, §§2.1, 2.5] |

Terrain spans source and propagation; wind spans propagation and additive noise. A one-factor label must not conceal these interactions. [Review interpretation: P04, §§1.2, 5–6; P13, chapter 3, §2.3]

## Waveform matching versus representation invariance

**Author evidence.** P02 and P14 change the training waveform distribution. P02 combines simplified physical sources with moving-source propagation; AudioLDM generates an entire acoustic observation, including whatever background/room characteristics its learned distribution contains. P06 demonstrates text-conditioned environment changes, not a calibrated dry-source output. [P02, §2.2; P14, §2; P06, §§3–4, Appendix I]

**Author evidence.** P16 aligns latent distributions with a domain discriminator and keeps source classification as an additional learning signal. P01's DANN acts on a trainable projection above a frozen encoder; ArcFace has no target-domain data and promotes class separation. BEATs pretraining seeks semantic tokens rather than reconstructing every acoustic detail. [P16, §2; P01, §2.3; P07, §3]

**Review interpretation.** These approaches are complementary possibilities, not interchangeable guarantees. A physically diversified waveform can still contain a synthetic shortcut. Domain alignment can remove useful class distinctions or align incompatible class mixtures. ArcFace should be described as source-supervised metric learning for domain generalization in this experiment, rather than target-distribution matching. [P02, §3.3; P01, §§2.3, 3.4; P16, §2]

## Does source mismatch dominate propagation mismatch?

**Evidence consistent with the hypothesis.** P02 directly describes impoverished procedural source structure, class-specific engine templates and missing broadband/dynamic detail. Altmann shows that relative harmonic balance depends on actual engine/exhaust configuration and state. Ronchini finds uneven semantic fidelity across generated classes. A richer source is therefore a motivated intervention. [P02, §3.3; P04, §5.3; P14, §4]

**Evidence limiting or challenging the hypothesis.** P02's more spectrally similar AudioLDM data does not clearly outperform procedural data at matched volume; useful diversity and spectral resemblance are different properties. P09 loses accuracy across stations, P13 observes terrain-dependent distributions, and P16 improves recognition through device adaptation alone. These show that non-source changes can matter substantially, although none measures their contribution to P02's synthetic-to-real gap. [P02, Table 5, §3.3; P09, §V; P13, chapter 3, §2.3; P16, Table 1]

**Attribution limit.** P01's authors conclude that environment/geography dominates microphone variation. Their comparison changes event familiarity, fleet, location, environment and sensor together: CH34 contains training events, whereas MELAUDIS contains different events. It supports the narrower observation that this same-event device test is easier than this cross-dataset test. It cannot quantify source versus propagation contributions, nor establish that sensors are generally unimportant. [Review interpretation: P01, §§2.5, 3.3–3.4]

**Verdict:** source-model dominance remains **unknown**. None of these papers estimates a crossed source × propagation × environment × sensor intervention on the same independent real target. [Review synthesis: P02, §§2.2–2.5; P01, §2.5; P14, §3; P16, §3]

## PDF audit and unresolved source inconsistencies

- P16 Table 1 has a malformed Markdown header. PDF p.4 fixes model/condition alignment; Figure 2 establishes ten scene labels (the prose on PDF p.2 duplicates “airport”). The equations were checked on PDF p.2; no repaired equation is needed for this review.
- P14 PDF pp.2–3 confirm Tables 1–2. The source itself says ten folds in §2.2 and “9-fold cross-validation” in §3; the exact rotation/validation procedure is **unknown**, not silently corrected.
- P02 PDF pp.8 and 11 confirm the main and matched-volume tables. PDF p.13 Figure 5 is captioned “balanced” but its row counts sum to 703, 75 and 241 (1019 total), not 75 per class. We do not treat that figure as the balanced evaluation. Its Table 6 also labels a baseline “balanced” while retaining N=1006; the baseline preprocessing distinction needs code-level reproduction. The reported “55%” relative gain uses precision unavailable in the rounded 0.25/0.39 values; quote it only as the authors' claim.
- P01 PDF pp.6 and 10 confirm the checkpoint and table values. Its blanket statement that MELAUDIS is excluded from training (§2.1) has an explicit DANN exception (§2.3.1). Its self-supervised-versus-supervised explanation is qualified by P07: BEATs **iter3+** uses a supervised teacher. The difference cannot establish a clean supervision-type effect. [P07, §4.3, Table 1]
- P06 PDF pp.5–6 and 8 resolve lost inpainting superscripts and merged metric columns. No missing values were inferred. Appendix F discusses fine-tuning and evaluating on AudioCaps; the paper's configuration describes AudioCaps training data, so its ambiguous “on the evaluation set” wording is not treated as proof of test-set training.
- Supplementary P08 PDF p.9 contains fuzzy-rule expressions where Markdown inserts an unrelated differential-equation paragraph. That conversion text was discarded.

## Handoff to final synthesis

The next step is to combine these findings into recurring causal gaps and a dependency-ordered experimental roadmap. The first deliverable of any future experiment must be an auditable domain-gap estimate using consistent labels, metrics, source grouping and real-data access. Mechanistic attribution requires subsequent controlled interventions; it cannot be obtained by subtracting unrelated headline scores. [Review interpretation: P01, §§2–4; P02, §§2–4; P14, §3]
